# Struktur aset gambar

- `logos/` berisi identitas HIMTI UNA dan Universitas Asahan.
- `affiliations/` berisi logo organisasi mitra.
- `people/` berisi foto tokoh linimasa sejarah, ilustrasi ketua, dan placeholder lokal.
- `pengurus/` berisi ilustrasi pengurus inti; `pengurus/kabid/` berisi ilustrasi kepala bidang.

File di `public/` dilayani apa adanya. Karena situs memakai base path `/himti-una/` di GitHub Pages, referensi dari komponen harus menyertakan awalan tersebut.
